# Phase Reports

Phase reports are project-specific working documents. Copy the relevant template or create the phase report named by `ROADMAP.md` inside the real project repository.

A phase report must record scope, completed work, incomplete work, blockers, files changed, tests, quality gate, and next phase. A failed quality gate stops progression until the blocker is fixed and re-audited.

The framework intentionally keeps phase reports out of the generic repository so the starter remains reusable across projects.
